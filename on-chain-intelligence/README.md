# Volume Verification & Integrity

As a BD Manager, my priority is ensuring that the partners we pay are delivering real value. I use a "Three-Pillar" check to verify that trading volume is organic.

### 1. Funding Trace
I check if new users are being funded by the same source. This prevents "Sybil attacks" where one person pretends to be 100 people to claim bonuses.

### 2. Activity Balance
I look for "Human" trading patterns. If a wallet with $50 is doing $50,000 in trades in one hour, it is likely a bot. I filter these out to save the company money.

### 3. Real-Time Monitoring
I use a custom dashboard to see which regions are actually growing and which partners are high-quality.
